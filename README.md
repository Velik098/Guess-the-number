# Игра «Угадай число»

## Обзор проекта

Это учебный курсовой проект с фронтендом на чистом HTML, CSS и JavaScript. Приложение реализует браузерную игру «Угадай число» с таблицей рекордов.

При запуске игры генерируется случайное число в диапазоне от 1 до 100. Игрок вводит своё имя, затем вводит предполагаемое число и получает подсказки. Приложение сообщает, больше или меньше загаданное число, считает количество попыток и сохраняет результат после победы.

Таблица рекордов хранится в `localStorage`, поэтому лучшие результаты остаются доступными после обновления страницы или повторного открытия проекта в браузере.

Проект сделан без фреймворков, библиотек, npm, webpack, Vite и серверной части. Его можно открыть через `index.html` и сразу использовать.

## Логика игры

При загрузке страницы вызывается функция `startNewGame()`. Она создаёт новое случайное число, обнуляет количество попыток, очищает поля ввода и подготавливает интерфейс.

Игрок вводит имя и число. После нажатия на кнопку «Проверить» вызывается функция `handleAnswer()`. Сначала она проверяет корректность введённых данных, затем сравнивает число игрока с загаданным числом.

Если введённое число меньше загаданного, приложение показывает сообщение «Загаданное число больше». Если введённое число больше загаданного, появляется сообщение «Загаданное число меньше».

Если игрок угадал число, игра завершается. Кнопка проверки блокируется, результат сохраняется в таблицу рекордов, а таблица сразу обновляется на странице.

Если игрок хочет отменить текущую партию или начать заново, он может нажать кнопку «Новая игра». В этом случае страница не перезагружается: создаётся новое случайное число, счётчик попыток сбрасывается, поля ввода очищаются, а таблица рекордов остаётся сохранённой.

## Проверка ввода

В проекте есть обработка ошибок:

- пустое имя игрока;
- пустое поле с числом;
- ввод текста вместо числа;
- ввод дробного числа;
- число меньше 1;
- число больше 100;
- попытка продолжить игру после победы.

Проверка находится в функции `validateInput()`. Она возвращает текст ошибки, если данные введены неправильно. Если ошибок нет, игра продолжает работу.

## Данные в localStorage

Приложение сохраняет рекорды в браузере по ключу:

```text
guessNumberRecords
```

Данные хранятся в виде массива объектов. Каждый объект содержит:

- `name` — имя игрока;
- `attempts` — количество попыток;
- `date` — дата победы.

Пример записи:

```javascript
{
    name: 'Анна',
    attempts: 5,
    date: '05.05.2026'
}
```

Если `localStorage` пустой, приложение работает без ошибок и показывает сообщение «Рекордов пока нет».

## Как работает таблица рекордов

После победы новый результат добавляется в массив рекордов. Затем массив сортируется по количеству попыток.

Чем меньше попыток понадобилось игроку, тем выше его место в таблице.

После сортировки сохраняются только 10 лучших результатов. Это сделано, чтобы таблица оставалась короткой и удобной для просмотра.

## Основные функции

`getRandomNumber()` — генерирует случайное число от 1 до 100.

`validateInput()` — проверяет имя игрока и введённое число.

`handleAnswer()` — обрабатывает попытку игрока.

`loadRecords()` — загружает рекорды из `localStorage`.

`saveRecords()` — сохраняет массив рекордов в `localStorage`.

`saveRecord()` — добавляет новый рекорд после победы.

`renderRecords()` — отрисовывает таблицу рекордов на странице.

`startNewGame()` — запускает новую игру.

`clearRecords()` — очищает таблицу рекордов.
